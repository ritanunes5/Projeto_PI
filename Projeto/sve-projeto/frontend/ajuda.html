Centro de Ajuda

1. Criar Conta

Aceda à opção "Criar Conta" e selecione o método de autenticação pretendido. Preencha os dados solicitados e conclua o registo.

2. Iniciar Sessão

O sistema permite autenticação através de:

  • Cartão de Cidadão
  • Chave Móvel Digital
  • Recenseamento Eleitoral

3. Participar numa Eleição

Após iniciar sessão, consulte as eleições disponíveis e selecione o candidato pretendido. Depois de confirmar o voto, este será registado no sistema.

4. Consultar Resultados

Os resultados podem ser consultados através da página "Resultados", onde é possível visualizar o número de votos obtidos por cada candidato.

5. Regras do Sistema

  • Cada eleitor pode votar apenas uma vez por eleição.
  • O eleitor deve ser maior de idade.
  • O eleitor deve estar recenseado.
  • As eleições são geridas pelos administradores do sistema.

6. Problemas Frequentes

Não consigo iniciar sessão.

Verifique os dados introduzidos e confirme que está registado no sistema.

Não consigo votar.

Verifique se já votou nessa eleição ou se cumpre os requisitos de elegibilidade.

Não vejo eleições disponíveis.

O administrador poderá ainda não ter criado ou ativado eleições.
