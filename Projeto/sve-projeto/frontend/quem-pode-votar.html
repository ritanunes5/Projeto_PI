Quem Pode Votar?

Requisitos para votar

Para poder votar no sistema, o eleitor deve cumprir os seguintes critérios:

  • Ter idade igual ou superior a 18 anos.
  • Estar registado no sistema como eleitor.
  • Estar recenseado.
  • Utilizar um dos métodos de autenticação disponíveis.
  • Não ter votado anteriormente na mesma eleição.

Métodos de autenticação disponíveis

  • Cartão de Cidadão
  • Chave Móvel Digital
  • Recenseamento Eleitoral

Voto único

Cada eleitor só pode votar uma vez por eleição. Após votar, o sistema bloqueia uma nova tentativa de voto nessa mesma eleição.

Privacidade do voto

O sistema regista que o eleitor já votou, mas guarda o voto separadamente. Assim, é possível impedir votos duplicados sem associar diretamente o eleitor ao candidato escolhido.
